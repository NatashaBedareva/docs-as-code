# API

API предоставляет доступ к функциям ИИ-сервиса.

## Основные операции

- `POST /analysis` — выполнить анализ отзыва;
- `GET /analysis/{id}` — Получить результат анализа по идентификатору;
- `GET /categories` — Получить список доступных моделей анализа.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
