# Data Sheet

## Общая информация

**Название датасета:**  
RuSentiment: An Enriched Sentiment Analysis Dataset for Social Media in Russian

**Источник:**  
https://aclanthology.org/C18-1064/

A. Rogers A. Romanov A. Rumshisky S. Volkova M. Gronas A. Gribov RuSentiment: An Enriched Sentiment Analysis Dataset for Social Media in Russian. Proceedings of COLING 2018.

**Назначение:**  
Анализ тональности русскоязычных постов в социальных сетях. Датасет создан для обучения и оценки моделей классификации текста по трём классам: positive, negative, neutral .

## Состав данных

**Объём:**  
31 185 постов

**Тип данных:**  
Тексты постов социальной сети «ВКонтакте» на русском языке. Короткие тексты разговорного стиля, характерные для социальных медиа .

**Основные поля / признаки:**  
Текст поста и метка тональности: positive, negative, neutral.

## Получение данных

Данные собраны из социальной сети «ВКонтакте». Для разнообразия выборки 6 950 постов были предварительно отобраны с использованием стратегии, похожей на активное обучение (active learning-style strategy) . 

## Предобработка

В оригинальной статье упоминается разметка с Fleiss' kappa = 0.58 (умеренное согласие между аннотаторами) и предварительный отбор части данных. Конкретные шаги предобработки текста (очистка, нормализация, токенизация) в доступных источниках не указаны.

## Ограничения

- Домен: данные из социальной сети «ВКонтакте», а не из отзывов на маркетплейсах. Стиль текста, лексика и структура могут отличаться от товарных отзывов.

- Согласие аннотаторов: Fleiss' kappa = 0.58, что означает субъективность разметки и потенциальный шум в метках .

- Язык: только русский язык.

- Длина текста: посты социальных сетей короткие; датасет не предназначен для длинных развёрнутых отзывов.

## Использование в проекте

Датасет RuSentiment — это обучающая основа для модели blanchefort/rubert-base-cased-sentiment-rusentiment, которая используется в проекте «Анализатор отзывов» для определения тональности отзывов покупателей.
