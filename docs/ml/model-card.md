**Язык:**  
Русский

## Использование в проекте

Модель используется для определения тональности отзыва: положительная, нейтральная или отрицательная.

Модель вызывается сервисом анализа (API) при обработке запроса POST /analysis: получает текст отзыва, возвращает класс тональности (positive / neutral / negative) и уверенность. Результат сохраняется в БД с resultId и в дальнейшем отдаётся через GET /analysis/{id}. Валидация текста выполняется до вызова модели. Ошибки обработки и недоступности модели описаны в OpenAPI-спецификации.

## Входные данные

Текст отзыва на русском языке.

## Выходные данные

Один из трёх классов тональности:

- `0` — NEUTRAL (нейтральная)
- `1` — POSITIVE (положительная)
- `2` — NEGATIVE (отрицательная)


## Метрики качества

Не указано авторами модели.

## Ограничения

- Длина входного текста ограничена 512 токенами — длинные отзывы обрезаются.

- Модель работает только на русских текстах.

Потенциальное ограничение для нашего проекта:

- Модель обучена на постах социальной сети «ВКонтакте» (датасет RuSentiment), а не на отзывах маркетплейсов — возможна потеря качества на специфических товарных текстах.

## Не рекомендуется использовать

Модель не предназначена для анализа текстов не на русском языке.
