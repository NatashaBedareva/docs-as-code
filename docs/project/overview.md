# Анализатор отзывов 

определяет тональность отзыва: положительная, нейтральная или отрицательная.

Основные пользователи:

- покупатели маркетплейсов
- продавцы на маркетплейсах

Основные функуции:

- отправка отзывов
- анализ тональности
- просмотр результата анализатора

## Комплект документации

1. Описание проекта (для заказчиков, команд,чтобы понимать цель проекта)

2. Требования (для аналитиков, разработчиков и тестировщиков, чтобы зафикчировать что должна делать система и по каким критериям принимать результат)

3. Архитектура системы (для разработчиков)

4. Документация ML-модели (для ML-инжинеров, как обучать и оценивать)

5. Руководство пользователя (для покупателей и продовцов, чтобы они могли пользоваться проектом)
